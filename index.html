Syntila Connect for Linux

Install Syntila Connect (the syntila-connect CLI and the Worker Engine) on Ubuntu 22.04 or newer, or any Debian-based system. Packages are available for amd64 and ARM64. Provider CLIs and their logins are installed separately. Current version: 0.1.0.

Install

curl --fail --location https://nohainc.github.io/syntila/syntila-archive-keyring.gpg -o /tmp/syntila-archive-keyring.gpg
gpg --show-keys --with-fingerprint /tmp/syntila-archive-keyring.gpg
sudo install -D -m 644 /tmp/syntila-archive-keyring.gpg /etc/apt/keyrings/syntila-archive-keyring.gpg
printf 'Types: deb\nURIs: https://nohainc.github.io/syntila\nSuites: stable\nComponents: main\nSigned-By: /etc/apt/keyrings/syntila-archive-keyring.gpg\n' | sudo tee /etc/apt/sources.list.d/syntila.sources
sudo apt update
sudo apt install syntila-connect

Check the key fingerprint: 6EA013D12EF79CBDC34D66058182CCCFCF4175F2.

Pair a Worker

In the web app add a Worker and copy its pairing code, then as your normal user:

syntila-connect pair --pairing-code CODE --auto-start
syntila-connect status

For startup without a login session run sudo loginctl enable-linger "$USER".
