# Northstar Studio scene script

All characters, organizations, and product details are fictional. Use the
[demo guide](README.md) for prerequisites, capture boundaries, and production
approval. The script describes intended actions, not completed evidence.

## 1. Launch overview

**Northstar Studio / Launch plan** — Show the Space and Thread navigation with
this opening message from Maya:

> Fieldnotes helps people capture and organize everyday ideas. Our launch brings
> together a clear store listing, a calm visual direction, and a useful website.
> We'll review the copy, accessibility, and release readiness before launch.

Frame the overview and navigation so the project and its other Threads are
legible.

## 2. Team discussion

**Northstar Studio / Launch plan** — Following the overview, each participant
sends their own message in the human conversation:

- Maya: “Our launch story should make it easy to see how Fieldnotes turns small observations into useful ideas.”
- Leo: “I’ll keep the visual direction calm and practical. A few clear examples will do more than a long feature list.”
- Amara: “For the store listing, let’s lead with capturing an idea quickly and finding it again later.”

Capture the three messages and their senders together where practical.

## 3. App Store copy

**Northstar Studio / App Store copy** — Select the Chat workflow and an
available, ready Worker and model. Submit:

> Draft three concise App Store subtitle options for Fieldnotes, an app that helps people capture and organize everyday ideas. Keep the tone clear and optimistic.

Review the actual response for consistency and capture the prompt, Worker/model
attribution, and response when suitable.

## 4. Website messaging

**Northstar Studio / Website messaging** — Select the Chat workflow and, if
available, a second Worker or model. Submit:

> Turn this positioning into a website hero headline, supporting sentence, and three short benefit statements. Avoid claims we cannot verify.

Provide the Fieldnotes positioning from scene 1 in the request context if needed.
Review and capture the actual distinct response with attribution. If no second
Worker or model is ready, record the limitation and defer this scene.

## 5. Launch checklist

**Northstar Studio / Launch checklist** — Select Work and a ready Worker/model.
Submit:

> Create a concise launch checklist for Fieldnotes covering store copy, visual review, accessibility, and release readiness. Group it by owner and include a clear definition of done.

Capture the completed execution and its reviewed result only if it actually
succeeds. Do not represent a draft, failure, or pending run as completed.

## 6. Visual direction

**Fieldnotes Design / Visual direction** — Show the second Space and Thread in
navigation. Maya posts:

> Visual direction: use a calm, practical layout and a few clear examples of
> collecting ideas. Leo will review the visual treatment before launch.

Capture the message with enough navigation to establish the second Space.

provider setup in the [Workspace guide](README.md#separate-demo-workspace-and-worker-setup).
Record actual Worker/model names and readiness at setup, not in advance. For
Chat, select a Worker whose current Profile is admitted for read-only execution;
for Work, verify the Workspace and Space authorization. Review the real scene 5
checklist for its four requested topics, owners and definition of done. When a
suitable Worker, second model, grant or execution is unavailable, record the
blocker and defer the affected capture; the prompt remains a storyboard only.
